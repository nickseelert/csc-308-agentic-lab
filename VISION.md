# Vision

A small public website that turns the 2026 MLB postseason into clear, honest charts and tables.
Students suggest features during a live lecture; an agent team builds them.

## What good looks like
- One feature per pull request, visible on the site after merge.
- Numbers a baseball fan would trust: correct definitions, sensible minimum sample sizes.
- Readable on a projector: plain layout, large type, no clutter.

## In scope
- New analyses of the committed Statcast snapshot (pitchers, hitters, pitch types, games, rounds).
- New charts, tables or pages on the static site.
- Fixes and clean-ups to existing analysis or site code.

## Out of scope (say no, or ask)
- Anything needing a server, database, login, API key or secret.
- Network calls in tests, CI or the site build.
- Betting, predictions presented as fact, or personal information beyond public player names.
- Rewriting the stack or the CI workflow.
